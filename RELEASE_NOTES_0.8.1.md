# SSGReciprocalDatabase 0.8.1

This maintenance release adds concise Wolfram Language help for every public
symbol. After installation, evaluate:

```wl
<< "SSGReciprocalDatabase`"
?SSGReciprocalDatabase`*
```

Each usage message now states the accepted input and the returned object. The
user guide also explains wildcard help, single-function help, Xiao SSG label
syntax, and `Missing`/`Failure` results.

No reciprocal-space records, magnetic-group identifications, or mathematical
classification results have changed from version 0.8.0.
